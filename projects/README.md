- `week-03-resilient-unstructured-data-extraction-pydantic-validation-pipelines/`
  - Week 3 project focused on resilient unstructured data extraction and Pydantic validation pipelines.
- `week-04-multi-provider-async-llm-gateway-real-time-telemetry-engine/`
  - Week 4 project for the multi-provider async LLM gateway and real-time telemetry engine.
- `week-05-semantic-document-search-engine-empirical-retrieval-benchmarking/`
  - Week 5 project for semantic document search and empirical retrieval benchmarking.
- `week-06-production-two-stage-rag-pipeline-query-rewriting-cross-encoder-reranking-adaptive-web-fallback/`
  - Week 6 project for two-stage RAG, conversation-aware query expansion, reranking, and optional web fallback.

Add new projects here as the term progresses.
